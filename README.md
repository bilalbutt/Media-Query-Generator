
# Media Query Generator!

Media Query Generator is a web app that helps developers create custom CSS media queries effortlessly. Simply input your breakpoints, select desired styles, and generate responsive CSS code instantly. Perfect for designing mobile-friendly websites with ease!

- Allows user to generate media queries effortlessly.
